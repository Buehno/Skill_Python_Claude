# Glossário de Bibliotecas

**Arcade** — jogos 2D com física, câmera e mapas Tiled prontos (Ch01→ch03).
**BeautifulSoup** — extrai tabelas/links/texto de HTML (ch09).
**Dash** — dashboards interativos ligados a gráficos Plotly (ch01).
**DearPyGui** — telas desktop que atualizam muitas vezes por segundo (ch02).
**DeepFace** — estima idade/emoção e verifica identidade facial (ch06).
**Django** — framework web completo com ORM, login e admin (ch01).
**FastAPI** — API com validação automática e documentação interativa (ch01).
**Flask** — micro-framework web sem estrutura imposta (ch01).
**Flet** — uma interface que roda como web, desktop e celular (ch02).
**GeoPandas** — pandas com geometria: cruza dados com regiões/bairros (ch12).
**Gradio** — interface web em volta de uma função (texto/imagem/áudio/webcam) (ch01).
**Kivy** — telas de toque/multitoque com empacotamento Android (ch02).
**MediaPipe** — rastreia mãos, rosto e corpo pela webcam em tempo real (ch06).
**MoviePy** — edita vídeo por código: corta, junta, sobrepõe texto (ch05).
**NetworkX** — grafos e redes: caminho mais curto, centralidade, comunidades (ch15).
**NLTK** — frequência de palavras, stemming, stopwords, sentimento básico (ch08).
**NumPy** — contas vetorizadas com matrizes, sem laço (ch04).
**OpenCV** — processa vídeo/webcam quadro a quadro (ch05).
**Peewee** — ORM simples, aprendido numa tarde (ch11).
**Pillow (PIL)** — abre, corta, redimensiona e filtra imagens (ch05).
**Playwright** — controla navegador real; estável e grava vídeo da execução (ch09).
**Plotly** — gráficos interativos no navegador (ch04).
**Pygame** — jogos 2D do zero: imagem, colisão, som (ch03).
**Pyglet** — janela, som e OpenGL para jogo/visualização 3D (ch03).
**PyAutoGUI** — move mouse e digita, automatiza qualquer programa na tela (ch13).
**PyInstaller** — empacota o projeto num executável standalone (ch16).
**PySide6 (Qt)** — interfaces com cara de programa comercial (ch02).
**Pymunk** — física 2D real: gravidade, colisão, mola, articulação (ch03).
**Rich** — terminal com cor, tabelas e barra de progresso (ch16).
**ReportLab** — gera PDF do zero com layout milimétrico (ch10).
**Scrapy** — varre um site inteiro em paralelo, exporta CSV/JSON (ch09).
**Seaborn** — gráficos estatísticos bonitos a partir do pandas (ch04).
**Selenium** — controla um navegador real: clica, digita, espera (ch09).
**SimPy** — simula filas e recursos limitados ao longo do tempo (ch15) — não confundir com SymPy.
**SpeechRecognition** — ouve microfone e transforma fala em texto (ch07).
**Streamlit** — vira um script Python em página web sem HTML (ch01).
**SymPy** — resolve equações simbólicas, deriva e integra (ch15) — não confundir com SimPy.
**SQLAlchemy** — ORM: cada tabela vira classe, portável entre bancos (ch11).
**Tkinter** — janelas, botões e diálogos, já vem com o Python (ch02).
**TinyDB** — guarda dicionários num arquivo JSON, sem esquema fixo (ch11).
**Typer** — transforma funções em comandos de linha de comando (ch16).
**Ultralytics YOLO** — detecta, segmenta e estima pose de objetos/pessoas (ch06).
**Ursina** — mundos 3D navegáveis em poucas linhas (ch03).
**cryptography** — cifra arquivos e guarda senha com segurança (ch16).
**customtkinter** — Tkinter com aparência moderna e tema claro/escuro (ch02).
**discord.py** — bots de Discord: comandos, moderação, música (ch14).
**EasyOCR** — lê texto em fotos, com bom suporte a português (ch06).
**face_recognition** — reconhecimento facial contra um cadastro (ch06).
**faster-whisper** — transcreve áudio localmente, com timestamps (ch07).
**feedparser** — lê feeds RSS de portais de notícia (ch09).
**folium** — mapas interativos com marcadores e camadas (ch12).
**fpdf2** — PDF simples com pouquíssimo código (ch10).
**geopy** — endereço vira coordenada; calcula distância real (ch12).
**gpiozero** — controla LED, relé, motor e sensores no Raspberry Pi (ch13).
**gTTS** — gera MP3 falado com voz natural, dezenas de idiomas (ch07).
**imaplib** — lê e-mails; já vem com o Python (ch14).
**librosa** — análise musical: BPM, batida, altura de nota, espectro (ch07).
**openpyxl** — escreve planilhas .xlsx com fórmula, cor e abas (ch04).
**paho-mqtt** — troca mensagens entre dispositivos IoT (ch13).
**pandas** — lê CSV/Excel, filtra, agrupa, soma, cruza tabelas (ch04).
**pdfplumber** — extrai tabelas de dentro de um PDF (ch10).
**psutil** — lê CPU, memória, disco, rede e processos da máquina (ch13).
**pydub** — corta, junta, converte e normaliza áudio (ch07).
**pyserial** — conversa por USB com Arduino, ESP32, balança (ch13).
**pytesseract** — OCR clássico, rápido em documento escaneado (ch06).
**pytest** — testes automáticos (ch16).
**python-docx** — cria e preenche documentos .docx (ch10).
**python-dotenv** — tira senhas/chaves de dentro do código (ch16).
**python-pptx** — monta apresentações .pptx a partir de modelo (ch10).
**python-telegram-bot** — bot de Telegram com comandos e alertas (ch14).
**pyttsx3** — fala texto com vozes do sistema, sem internet (ch07).
**pypdf** — junta, separa, gira e extrai texto de PDFs existentes (ch10).
**pyzbar** — lê QR Code e código de barras (ch05).
**qrcode** — gera QR Code (ch05).
**rapidfuzz** — acha textos parecidos, tolera erro de digitação (ch08).
**rembg** — remove o fundo de uma foto com um comando (ch05).
**requests** — busca páginas e consome APIs via HTTP (ch09).
**schedule** — agenda tarefas dentro do próprio programa (ch13).
**scikit-image** — segmenta, conta e mede objetos numa imagem (ch05).
**scikit-learn** — aprendizado de máquina clássico: prever, classificar, agrupar (ch04).
**SciPy** — otimização, estatística, filtro de sinal, ajuste de curva (ch04).
**sentence-transformers** — busca por sentido semântico, não por palavra igual (ch08).
**smtplib** — envia e-mails com anexo; já vem com o Python (ch14).
**sounddevice** — grava e processa som em tempo real (ch07).
**spaCy** — entende gramática e entidades (nomes, lugares, datas) em português (ch08).
**supervision** — conta cruzamentos de linha e delimita zonas sobre um detector (ch06).
**transformers** — modelos prontos de tradução, resumo e classificação (ch08).
**watchdog** — avisa quando um arquivo aparece ou muda numa pasta (ch13).
